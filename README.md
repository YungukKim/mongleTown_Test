# 몽글마을! — 프런트엔드 프로토타입

PRD 검토용으로 HTML·CSS·순수 JS만으로 만든 화면 프로토타입이에요. 백엔드 없이 브라우저 `localStorage`에 데이터를 저장하고, 결제는 실제로 일어나지 않아요.

## 실행

ES 모듈을 쓰지 않아 `index.html`을 그대로 열어도 되지만, 로컬 서버로 여는 걸 권장해요.

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

브라우저에서 http://localhost:5173 을 열고 **체험 계정으로 둘러보기**를 누르면 바로 들어갈 수 있어요.
처음 상태로 되돌리려면 마이페이지 → **데모 데이터 초기화**를 누르세요.

## 구조

```
index.html          앱 셸 (상단 바, 하단 탭바, 토스트, 모달 영역)
css/style.css       연필 선화 디자인 시스템
js/icons.js         선화 아이콘
js/data.js          아이템 카탈로그·집·충전 상품·이웃 시드 (→ items, homes, products 테이블)
js/store.js         localStorage 저장소 (PRD 9.1 테이블 이름을 따름)
js/api.js           가짜 API. 화면은 이 객체만 호출함 → 백엔드 연동 시 fetch로 교체
js/ui.js            토스트, 모달, 확인 창, 공통 도우미
js/pages/*.js       화면별 코드 (auth, village, room, social, shop, mypage, admin)
js/app.js           해시 라우터와 메뉴
```

## 가짜 API가 흉내 내는 서버 규칙

백엔드에서 그대로 지켜야 할 규칙을 `js/api.js`에 미리 넣어 두었어요.

- 이미 점유된 집에는 입주할 수 없고, 이사는 이전 집 비우기와 새 집 점유를 한 번에 처리
- 방 저장 시 보유하지 않은 아이템, 같은 인스턴스 중복 배치, 범위 밖 좌표를 거절
- 아이템 구매는 잔액 확인 → 차감 → 지급을 한 번에 처리하고, 멱등 키로 중복 차감을 방지 (무료 몽글부터 사용)
- 충전은 서버가 주문과 금액을 만들고, 승인 시 금액을 비교해 1회만 지급. 결제 실패·취소·중복 승인·금액 위변조를 감사 로그에 기록
  - 충전 화면의 "검토용 테스트 옵션"에서 각 경우를 직접 확인할 수 있어요.
- 쪽지 500자 제한, 분당 5건 제한, 수신 범위(모두/친구만/받지 않음), 차단 시 쪽지·친구 요청 차단
- 방 좋아요는 한 사람당 한 방에 1번(다시 누르면 취소), 내 방·차단 관계에서는 불가
- 친구 요청 중복 방지, 거절 후 24시간 재요청 제한, 시간당 10건 제한
- 재화는 잔액 숫자 대신 원장(`walletTx`)의 합으로 계산하고, 관리자 조정은 사유가 필수

## 아직 정하지 않은 것 / 백엔드 단계에서 할 일

- 실제 인증(이메일 발송, 세션·토큰), 비밀번호 해시는 데모용 SHA-256
- 토스페이먼츠 SDK 연동과 시크릿 키를 쓰는 서버 승인 API
- 환불 정책: 지금은 유료 몽글이 충분할 때만 환불하도록 해 두었어요
- 관리자 권한 분리 (지금은 로그인한 누구나 데모 관리자 화면에 들어갈 수 있어요)
- 이웃(NPC)의 자동 답장·친구 수락은 데모 연출이에요
